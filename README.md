# Агрегатор новостей

Консольное приложение: собирает новости по RSS, хранит в SQLite, ищет и анализирует.

## Технологии

Java 21, Gradle, SQLite (JDBC), Jsoup, Gson, JUnit 5.

## Запуск

```bash
./gradlew run     # запуск
./gradlew test    # тесты
./gradlew build   # сборка
```


## Команды

```
1. Обновить новости (собрать)
2. Показать новости
3. Поиск и фильтрация
4. Аналитика
5. Источники
6. Экспорт (CSV/JSON/HTML, папка exports/)
7. Автообновление
8. История изменений
9. Удалить устаревшие новости
0. Выход
```

Источники задаются в пункте 5 или в `src/main/resources/sources.json`.
